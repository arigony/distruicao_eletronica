Por que um gás excitado não emite todas as cores?

3 · Questione o modelo clássico

Podemos acompanhar o elétron como um planeta?

O elétron apresenta comportamento ondulatório. Além disso, posição e momento não podem ter dispersões arbitrariamente pequenas ao mesmo tempo.

Comprimento de onda de de Broglie

Considere um elétron acelerado a partir do repouso.

λ = h/p = h/√(2mₑeU)

Modelo não relativístico. Aumentar U aumenta o momento e diminui o comprimento de onda.

Quanto podemos restringir a posição?

Δx Δpₓ ≥ ℏ/2
Δvₓ ≥ h/(4πmₑΔx)

Δx e Δpₓ são desvios-padrão. O resultado mostrado é um limite inferior, não uma medida da velocidade do elétron.

5 · Dê significado à equação

O que procuramos ao resolver Schrödinger?

Procuramos estados fisicamente admissíveis e suas energias. Explore os termos antes de interpretar a equação completa.

Ĥψ = Eψ

Para uma partícula em um potencial

−(ℏ²/2m)∇²ψ + Vψ = Eψ

O primeiro termo envolve a energia cinética; V representa a energia potencial. ∇² é a soma das segundas derivadas espaciais.

∇²ψ = ∂²ψ/∂x² + ∂²ψ/∂y² + ∂²ψ/∂z²

Para um átomo com vários elétrons, a equação completa envolve todos eles. A descrição por orbitais individuais é uma aproximação.

Densidade de probabilidade

ρ = |ψ|²

Indica como a probabilidade se distribui no espaço. Para uma função espacial tridimensional normalizada, sua unidade é m⁻³.

Probabilidade em uma região

P(Ω) = ∫Ω |ψ|² dτ

A integral soma a densidade dentro da região Ω. O resultado é adimensional e fica entre 0 e 1.

Uma função normalizada apresenta ∫todo o espaço|ψ|²dτ = 1. O que isso significa?
6 · Construa os estados permitidos

É possível existir um orbital 2d?

Use as relações entre os números quânticos para decidir. Os controles permitem montar combinações inválidas para investigar o erro.

ℓ = 0, …, n−1   ·   mℓ = −ℓ, …, +ℓ
Orbitais no subnível = 2ℓ+1
Elétrons no subnível ≤ 2(2ℓ+1)
Elétrons na camada ≤ 2n²

2n² indica capacidade máxima, não a ordem de preenchimento dos subníveis.

Construa mentalmente a camada n = 3: 3s tem 1 orbital, 3p tem 3 e 3d tem 5. Quantos elétrons cabem, no máximo, nessa camada?

Como os elétrons ocupam os estados?

Monte a configuração fundamental. Cada botão representa um orbital. Clique para alternar entre vazio, ↑, ↓ e ↑↓.

Quadro de ocupação, não uma escala de energia. A interface limita cada orbital a dois elétrons com spins opostos, incorporando o princípio de Pauli.
